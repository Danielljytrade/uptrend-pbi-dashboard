# UPTREND Power BI-Style Dashboard

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run:
   `pip install -r requirements.txt`
4. Run:
   `streamlit run app.py`

The dashboard opens in your browser. Upload a new daily CSV from the **Upload Data** page.

## Deploy
Upload these files to a GitHub repository, then deploy the repository on Streamlit Community Cloud. Set `app.py` as the entry point.
